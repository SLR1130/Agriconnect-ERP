The following Mermaid diagrams are source documentation. They are deliberately kept as text so they can be reviewed and regenerated by an academic team without changing application code.

## 8. Integrated activity — assistance to inventory

```mermaid
flowchart TD
    Start([Start]) --> Verify{Farmer verified in FFRMS?}
    Verify -- No --> Stop1[Reject access / request verification]
    Verify -- Yes --> Apply[Farmer submits AASMS application]
    Apply --> Eligible{Program eligibility passes?}
    Eligible -- No --> Return[Show validation / do not create eligible application]
    Eligible -- Yes --> Review[MAO reviews application]
    Review --> Decision{Approve?}
    Decision -- No, reject/return --> Notify1[Persist review history and notify farmer]
    Decision -- Yes --> Allocation[Persist approved quantity and supply item]
    Allocation --> Batch{Matching available, unexpired AISMS batch?}
    Batch -- No --> Hold[Reject distribution; retain approved application]
    Batch -- Yes --> Release[InventoryService locks batch and releases quantity]
    Release --> Distribution[Create assistance distribution with operation key]
    Distribution --> Complete[Mark application completed and notify farmer]
    Complete --> End([End])
```

## 9. Integrated sequence — verified assistance distribution

```mermaid
sequenceDiagram
    actor Farmer
    participant FFRMS as FFRMS / Farmer record
    participant AASMS as AASMSController
    participant Eligibility as ProgramEligibilityService
    participant Assistance as AssistanceService
    participant Inventory as InventoryService
    participant DB as Shared database
    participant Notify as Database notification

    Farmer->>AASMS: POST farmer.assistance.apply(program)
    AASMS->>FFRMS: Load authenticated farmer
    AASMS->>Eligibility: requireEligible(program, farmer)
    Eligibility->>DB: Read verified farmer, farms and program rules
    DB-->>Eligibility: Eligibility result
    Eligibility-->>AASMS: passed
    AASMS->>DB: Create assistance_application(status=submitted)
    Farmer->>AASMS: MAO review form is submitted
    AASMS->>Assistance: status(application, approved, quantity, supply item)
    Assistance->>DB: Update application + assistance_status_histories
    Assistance->>Notify: Notify farmer of approval
    AASMS->>Assistance: distribute(application, batch, quantity, key)
    Assistance->>Inventory: release(batch, quantity, key)
    Inventory->>DB: Lock batch, decrement balance, create release movement
    Inventory-->>Assistance: Movement reference
    Assistance->>DB: Create distribution and mark application completed
    Assistance->>Notify: Notify farmer of completed distribution
    AASMS-->>Farmer: Redirect with persisted success message
```
